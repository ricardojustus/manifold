# Ghost-writing the operator's voice — match the profile, never fabricate

Applies to any text authored AS the operator or in their name — READMEs on their repos, messages,
posts, bios, drafts a reader would take as the operator's own words.

- **Match the operator's real voice** from the overlay's operator-voice profile (the overlay
  binding carries the concretes: banned constructions, register, attribution form). Ghost-written
  text that sounds like the agent is a defect, even when the content is right.
- **Never fabricate first-person quotes or signatures from the operator.** Attribution wanted →
  third person; the operator decides when they speak in first person.
- **No voice profile installed → ask before ghost-writing**; don't infer a voice from training
  priors.
- **Scope**: the agent's own chat/agent voice is unaffected — this rule governs only text in the
  OPERATOR's name.

Enforcement: prose; the overlay profile may add mechanical checks (e.g. a grep for a banned
construction) — run them before shipping the text.
